# Claude Design 発注書：アイビーラボ コーポレートサイト（aibee-lab.jp）

> 第4版。「とりあえず47」の運営元プロフィールサイト（aibee-lab.jp）のビジュアルデザイン用ブリーフ。実装は別途 Claude Code（Next.js 16 ＋ Tailwind v4）。技術構成は `SITE_ARCHITECTURE.md` を参照。**構成と文言の正は本書**（SITEMAP.md・文言ドラフトを統合済み）。

## 0. このブリーフの使い方

- デザインは**単一アイデンティティ**（just47 のような2層構造は無い。テーマ切替なし）。
- 作る順：**トップ → /contact → /privacy → 404**（4ページとも作成完了。§8）。
- **文言は §4〜§6 の確定文言をそのまま使う**（デザインの都合で書き換えない。変更が必要ならオーナーへ報告）。
- ロゴは**既存の SVG ロゴを使用**（筆記体の「a」マーク＋「アイビーラボ」＋「AiBee Lab」。原版は濃色パネル `#22424d` 地・白抜き文字）。**サイトのヘッダーでは単色インク版**（パネルなし・文字をインク色に差し替えた派生 SVG）を使う。原色パネル版は favicon・OG 画像のマスター（§7）。
- ダークモードは初版では対応しない（ライトのみ）。

## 1. プロジェクト概要

- **役割**：スマホアプリポータル「とりあえず47」（just47.jp）の**運営元プロフィール**。読者の大半は just47 フッターの「運営」リンクから来る**非エンジニアの一般アプリユーザー**（スマホ・滞在数十秒〜数分）。本サイトが最も働くのは、アプリに課金が入ったとき——「お金を払っても大丈夫な相手か」の確認先。
- **受注サイトにしない**：クラウド／AI の事業内容は「売るため」ではなく「素性を示すため」の記述。料金・導入フロー・強い CTA は置かない。CTA は「お問い合わせ」1系統のみ。
- **識別子**：正式表記 **アイビーラボ**（英語表記 **AiBee Lab**・ロゴ準拠で B は大文字。補助表記）。ドメイン www.aibee-lab.jp。
- **声のトーン**：主語は「アイビーラボ」「私たち」。ポエム禁止・感動の押し売り禁止・事実で組む。静かで実直。just47 の「とぼけた軽さ」は持ち込まない（あちらはプロダクトの声、こちらは運営元の声）。ビジュアルも just47 とは明確に別のトーンにする（§2）。

## 2. ビジュアルアイデンティティ

**方針：just47 とは明確に別のトーンを持つ。清潔・実直・技術系。** 第3版までは「just47 と家族的類似（暖オフホワイトの地と明朝見出しを共有）」を採っていたが、実物を並べたところ**近すぎた**ため方針を変更した（第4版）。信頼のハンドオフはキッカー「「とりあえず47」運営元」とフッターの相互リンク＝**言葉の側で既に担保されている**ため、視覚の連続性は不要。むしろ「運営元は別の顔を持つ組織」と見えるほうが、課金前の確認先としては筋が通る。

**地（base）**
- **純白寄りのクリーンな白**（`#FFFFFF`〜`#FCFCFD` 前後）。暖色を持たせない。just47 の紙っぽい暖かみと明確に分かれる。セクションの区切りに、ごく淡いニュートラルグレーの面を使ってよい。

**文字（ink）**
- ニュートラルなチャコール〜黒に近い濃色（暖グレーにしない）。

**差し色（accent）**
- **ディープネイビー `#24405E`**（第2版から継続）。リンク・ボタン・英字ラベルに限定使用。抑えた1色のみ。
- ロゴ原版のパネル色 `#22424d` はティール圏のためサイト上では使わない（ヘッダーは単色インク版ロゴ。§0）。

**モチーフ・テクスチャ**
- モチーフ**なし**。テクスチャ**なし**（紙のグレインを持たせない）。フラットで清潔。

**タイポグラフィ**
- **見出し・本文とも Noto Sans JP**（第3版までの「見出し＝Noto Serif JP」から変更）。明朝は just47 と共有していた「声」なので使わない。
- 見出しはウェイトと級数の差で階層を作る。セクション見出しは**英字ラベル（小・トラッキング広め）＋日本語見出し（主）**の2段構成を維持（対応表は §4.1）。

**組版の力点**
- 本サイトは**表が主役級**（実績・沿革・概要）。罫線は細く・ニュートラルに、行間広めに、表を美しく組む。
- 余白広め・1カラム中心の静かなレイアウト。
- **モバイルファースト**（主読者はスマホから来る）。

**避けるもの**
- 営業 LP 感（強い CTA・数字の誇張・バッジの列）／ポエム見出し／過剰装飾／量産コーポレートテンプレ感／低コントラスト／**just47 と共通の要素（暖色の地・明朝見出し・紙のテクスチャ）**。

### 4.3 `/privacy`（全文）

制定日：●●（公開日で確定。実日付はリリース時に記入）

**1. 適用範囲**
本ポリシーは、アイビーラボ（以下「当ラボ」）が運営する本サイト（www.aibee-lab.jp）に適用されます。当ラボが運営するアプリ、および「とりあえず47」のサイトにおける情報の取り扱いについては、それぞれのサイト・アプリのプライバシーポリシーに定めます。

**2. お問い合わせで取得する情報と利用目的**
お問い合わせフォームでは、氏名・メールアドレス・お問い合わせ内容をお預かりします。これらは、内容の確認とご返信、および受付確認メールの送信のために利用し、それ以外の目的には利用しません。お預かりした内容は、当ラボが管理するデータベースに保存します。

**3. スパム対策のための情報の一時保存**
連続した送信を防ぐため、フォームの送信時に IP アドレスを復元できない形式（ハッシュ化）で一時的に保存します。この情報は送信回数の確認のみに使用し、一定時間の経過後に自動で削除されます。

**4. Cookie について**
当サイトは Cookie を使用していません。アクセス解析ツールも使用していません。

**5. ホスティングについて**
当サイトは AWS（アマゾン ウェブ サービス）上で運用しており、お預かりした情報も AWS 上で保管します。

**6. 本ポリシーの改定**
本ポリシーの内容は、必要に応じて改定することがあります。改定した場合は、本ページでお知らせします。

**7. お問い合わせ先**
本ポリシーに関するお問い合わせは、[お問い合わせフォーム]からお願いします。
